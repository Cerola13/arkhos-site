# Site da Arkhos AI

Espelho **público** do site da Arkhos AI, publicado via GitHub Pages em https://arkhosia.com.br

Este repositório contém **apenas** a página pública e os arquivos de logo.
O desenvolvimento acontece no repositório privado `Cerola13/git-hub` — este aqui é só o deploy.

## Como atualizar

1. Edite o `index.html` no repo privado
2. Copie o arquivo pra cá
3. `git commit` + `git push` — o GitHub Pages publica sozinho

Identidade visual: ver `brand/BRAND-WEB.md` no repo privado.
